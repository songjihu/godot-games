# 方块消除：发布与广告

## 已预留

- `ad_config.gd` 集中管理广告开关与广告位ID，默认全部关闭，不影响普通游玩。
- 激励视频：结算页自愿选择“看视频，撤销一步”。每局最多一次，完整观看且成功回调后才撤销；提前关闭、加载失败和重复回调不发奖励。没有广告就继续使用“再来一局”。原来的免费撤销不取消。
- 横幅：底部区域由 `banner_rect` 标出；打开 `BANNER_RESERVED` 后棋盘和按钮给底部让位。这里只预留布局，不会请求或显示横幅。真正接入还需处理原生广告实际高度、安全区、横竖屏与弹窗时隐藏，不要仅填写ID就当作完成。
- 激励视频通过已有 MiniGameSDK 接入。获得真实广告位后设置 `REWARDED_UNIT_ID` 并打开 `REWARDED_ENABLED`，重新导出。手机实测完整观看、提前关闭、无广告、断网和重复点击之后再提审。
- 尚未开通流量主、创建广告位、验证真实广告，也没有代为上传或发布。

## 正式发布步骤

1. 登录 https://mp.weixin.qq.com/ ，确认是《方块消除》独立小游戏账号及AppID。现包使用 `wxc19585dea4453b6b`；如它属于另一个游戏，不能上传覆盖，先取得本游戏AppID再运行 `export.ps1 -AppId 新AppID`。
2. 在后台完善名称、图标、简介、游戏类目、主体资料及联系方式。按该账号后台提示完成认证、备案与游戏资质。免费广告游戏不等于自动免软著、免备案或免版号；具体材料以该主体、类目和运营方式对应的后台要求为准。
3. 按实际功能填写用户隐私保护指引；当前成绩和进度保存在本地，无登录、支付或云排行。后续广告SDK接入后应重新核对其数据处理说明。
4. 核实美术、字体、音效与配音商业使用权。B3来自公开08样本的本地参考合成；目前没有取得原样本声线的商业授权证明，不能把模型Apache许可证理解为参考声音授权。上线前取得许可，或改用有明确商业授权的配音素材。
5. 微信开发者工具导入 `wechat` 目录，选择正式AppID，使用手机扫码预览。检查首次加载、触摸、音频、前后台切换、存档、适配及包体检查；按工具提示处理上传限制。
6. 点击开发者工具右上角“上传”，版本号如 `1.0.0`，备注如“方块消除首发，无广告”。上传代码不会直接上线。
7. 回公众平台找到“版本管理”中的开发版本，先设为体验版供测试人员扫码验证，再提交审核；如菜单名称调整，找“开发管理/版本管理”。填写真实功能说明，完成后台要求的审核项目与材料。
8. 审核通过后，在后台审核版本中点击“发布”。再用正式入口检查一次。审核被拒时按具体理由修复、重新上传提审。
9. 开通广告变现时，在后台“流量主/广告变现”按账户实际资格申请，补充结算资料并创建广告位。取得 `adunit-...` 后再启用代码、真机测试、上传新版本提审。没有广告资格或ID不影响先发布无广告版本。
