# 微信小游戏修复

- 使用设备像素比提升画布清晰度。
- 全窗口画布与 expand 比例适配，底部按钮按实际高度定位。
- 游戏直接处理触摸命中，关闭触摸转鼠标，避免重复计分。
- 兼容触摸坐标别名及缺失 changedTouches 的结束事件。
- 已移除临时诊断代码，并更新现有微信工程、微信压缩包和游戏源码包。

验证：适配层 Node 测试通过；Godot 无界面测试通过，包括经 Viewport 分发的触摸开始、单次计分、点空白、超时、重开及三种窗口尺寸布局。本轮没有操作桌面，微信模拟器与手机效果由用户手动验收。

手动测试：现有微信开发者工具项目点击“编译”；如显示旧画面，关闭项目后重新打开。点击 START GAME，再点 +1，每次应加 1 分。切换手机尺寸检查背景填满小游戏可绘制区域，底部按钮不被截断。微信系统状态区、胶囊按钮由宿主控制。
